Los datos son inventados. Nombres, cifras e importes son de prueba, para que se vea cómo se comporta el sistema con volumen real. Esta versión publicada es estática: se navega entera, pero los botones que escriben en base de datos — guardar, crear, cambiar estado — no graban nada. La aplicación de verdad, con su base de datos y sus webhooks, está en el repositorio.
